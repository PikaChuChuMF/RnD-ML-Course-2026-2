# Rossmann Store Sales | ДЗ1 по ML R&D

На последних 42 днях в `train.csv` модель с историей продаж снизила RMSPE с 20,33% до 15,64%. Ошибка стала на 23,05% ниже при пороге улучшения 5%.

## 1. Постановка задачи

Прогнозируем дневную выручку каждого магазина Rossmann на шесть недель вперед. Такой прогноз помогает планировать график сотрудников. Для каждого магазина строим прогноз сразу на все 42 дня. Горизонт взяли из описания контеста. [Rossmann Store Sales на Kaggle](https://www.kaggle.com/c/rossmann-store-sales)

Основную проверку проводим на 1115 магазинах из `train.csv`. В официальном `test.csv` 48 дней, с 1 августа по 17 сентября 2015 года, и 856 магазинов. Из этого файла берем список магазинов для дополнительной проверки на тех же 42 днях из `train.csv`.

> **Гипотеза.** Если добавить к линейной регрессии признаки из истории, рассчитанные только по данным до начала основного 42-дневного окна, RMSPE на этом окне снизится как минимум на 5% относительно той же модели без этих признаков.
>
> Базовая модель учитывает типичный уровень продаж каждого магазина и общий для сети недельный профиль. История помогает учесть, как продажи меняются по дням недели в конкретном магазине.

Обе версии линейной регрессии используют магазин, календарь и запланированное промо. Во вторую добавляем девять признаков из истории продаж. Сравниваем версии на одних и тех же строках. Порог выбрали до эксперимента.

## 2. Формализация

| Что | Определение |
|---|---|
| Тип задачи | Прогноз по нескольким временным рядам, по одному на магазин |
| Единица наблюдения | Один день одного магазина (`Store`, `Date`) |
| Цель `y` | Дневная выручка `Sales` |
| Признаки `X` | Номер магазина, день недели, месяц и запланированная акция. Для второй модели добавляем данные о прошлых продажах |
| Одно предсказание | Сколько выручки получит магазин в этот день. Если магазин не будет работать, прогноз равен нулю |

В момент прогноза считаем, что на все 42 дня уже известны запланированные акции (`Promo`) и дни, когда магазин будет работать (`Open`). При `Open = 0` ставим прогноз 0, потому что в этот день магазин не работает. В `test.csv` у магазина 622 значение `Open` пропущено в 11 строках. Для прогноза в контесте нужно будет решить, как обрабатывать такие случаи.

## 3. Данные и их анализ

В `train.csv` 1 017 209 строк по 1115 магазинам, с 1 января 2013 по 31 июля 2015. Для каждого дня записаны выручка, число покупателей, работал ли магазин, была ли акция и был ли праздник. Один магазин встречается в каждой дате максимум один раз. Во всех имеющихся строках поля заполнены.

- У 180 магазинов нет записей ни за один из 184 дней с 1 июля по 31 декабря 2014 года. Из-за таких пропусков продажи за дату год назад доступны не всегда. В основном окне таких случаев 5030 среди дней с положительной выручкой. Как заполняем пропуски, описано в разделе 4.
- В 172 871 строке выручка равна нулю. В 172 817 случаях магазин в этот день не работал. Еще в 54 случаях магазин был открыт, но выручка все равно записана как нулевая.
- Примерно 93% положительных значений дневной выручки лежат между 2000 и 12 000, медиана равна 6369. Отдельно проверяем, насколько редкие всплески влияют на прогноз.
- Чтобы избежать утечки, строим прогноз только по информации, доступной на тот момент. Например, фактическое число покупателей (`Customers`) и выручку за дни, которые предстоит спрогнозировать, узнаем позже. Для проверки откладываем последние даты целиком.

Распределение выручки и сравнение дней с акциями и без них показаны в ноутбуке.

## 4. Базовая модель

Сравниваем две версии линейной регрессии. Первая использует магазин, день недели, месяц и признак акции `Promo`. Вторая дополнительно получает девять признаков из прошлых продаж.

| Исторический признак | Как считаем до даты прогноза |
|---|---|
| Медиана магазина | Медиана положительных продаж магазина |
| Медиана по магазину и дню недели | Медиана положительных продаж для того же дня недели |
| Недавняя выручка | Средняя положительная выручка за последние 28 дней |
| Тренд | За каждую из последних восьми недель считаем среднюю выручку по дням с продажами. Сглаживаем ряд экспоненциальным средним (`span=3`) и берем наклон прямой по сглаженным значениям |
| Продажи год назад | Выручка за дату на 364 дня раньше, чтобы сохранить день недели |
| Типичная выручка во время акций | Медиана положительной выручки за прошлые дни с акциями. Для будущих дней без акции значение признака равно нулю |
| Выручка за 28 дней до прогноза | Выручка магазина ровно за 28 дней до начала окна. Значение одно и то же для всех 42 дат прогноза |
| Разброс недавней выручки | Стандартное отклонение положительной дневной выручки за восемь недель |
| Недавняя выручка в тот же день недели | Медиана положительной выручки в этот день недели за последние восемь недель |

Если данных для средней или медианы нет, используем медиану магазина, а при ее отсутствии медиану по всей сети. Если нет записи год назад или недавней медианы по дню недели, берем медиану по этому дню недели за всю доступную историю магазина. При расчете тренда пропускаем недели без продаж и сохраняем номера остальных недель. Если таких недель меньше двух, ставим ноль. Если дней с продажами меньше двух, разброс тоже равен нулю. Запись за 28 дней до прогноза заменяем медианой магазина только при ее отсутствии.

Для магазина, дня недели и месяца используем one-hot кодирование. Числовые признаки приводим к сопоставимому масштабу. У обеих моделей одинаковые настройки, включая свободный член.

Обучаемся на днях с положительной выручкой и используем цель `log1p(Sales)`. На шкале выручки промах на 1000 имеет одинаковый вес при факте 2000 и 20 000. На логарифмической шкале он сильнее влияет на обучение при факте 2000. Так штраф за небольшой промах ближе к относительной ошибке, которая важна для RMSPE. После прогноза возвращаемся к исходной шкале через `expm1`, заменяем отрицательные значения нулем и считаем метрики по этим прогнозам.

## 6. Протокол оценки

Основной период проверки длится с 20 июня по 31 июля 2015 года. За эти 42 дня есть 46 830 строк, из них 40 282 с положительной выручкой. Еще два более ранних периода по 42 дня помогают проверить, повторяется ли результат.

1. Для обучения разбиваем прошлые даты на периоды по 42 дня. Для каждого периода считаем исторические признаки только по продажам до его начала. В основном эксперименте обучаемся на 747 397 строках с положительной выручкой, со 2 марта 2013 по 19 июня 2015. Данные до 2 марта нужны для расчета первых признаков.
2. Кодирование категорий и масштабирование числовых признаков настраиваем только на обучающих данных. Обе модели оцениваем на одних и тех же магазинах и датах.
3. RMSPE измеряет ошибку относительно фактической выручки. Считаем `(прогноз - факт) / факт` для каждой строки, возводим ошибки в квадрат, усредняем и берем корень. Как в контесте, в расчет входят дни с положительной выручкой. На тех же строках считаем MAE, среднюю абсолютную ошибку в единицах выручки.
4. Основную гипотезу проверяем на двух заранее выбранных версиях по RMSPE. Остальные сравнения отвечают на исследовательские вопросы.

### Как проверяем каждый вопрос

1. Тренд. Обучаем полную модель и такую же модель без признака тренда. Сравниваем RMSPE и MAE на всех 40 282 днях с положительной выручкой в основном периоде.
2. Продажи год назад. Обучаем полную модель и такую же модель без продаж за дату 364 дня назад. Оцениваем их на одних и тех же 35 252 строках основного периода, для которых прошлогодняя запись существует. Так измеряем вклад фактических прошлогодних продаж без подстановки медианы в этом сравнении.
3. Всплески. Сравниваем два прогноза, полученных из исходной истории и из истории после удаления всплесков.

   1. Берем записи с положительной выручкой строго до 20 июня 2015 года. Для каждого магазина считаем медиану отдельно по каждому дню недели. Строка считается всплеском, если ее выручка не меньше трех таких медиан. Например, при медиане 2000 для суббот всплеск начинается с 6000.
   2. Считаем долю отмеченных строк среди всех дней с положительной выручкой отдельно для каждого магазина. В проверку входят магазины, у которых есть хотя бы один всплеск и их доля не превышает 1%.
   3. Из копии всей истории до 20 июня убираем отмеченные строки целиком. По оставшимся записям заново считаем девять исторических признаков. Например, если удаленная строка давала выручку год назад, вместо нее подставляем медиану по магазину и дню недели.
   4. Используем одну уже обученную модель для обоих вариантов. Сравниваем прогнозы с фактом за те же дни с положительной выручкой у выбранных магазинов. Считаем RMSPE, MAE и величину изменения каждого прогноза.

   Отдельно сравниваем две обученные модели, одна из которых использует среднее вместо медианы по магазину и дню недели. Для обеих берем исходную историю и те же дни оценки.

### Подбор регуляризации

Проверяем L2-регуляризацию с `alpha` 0,1, 1, 10 и 100. Для каждого значения обучаем модель с историей отдельно перед двумя ранними периодами. Выбираем `alpha` по среднему RMSPE этих двух проверок. На последних 42 днях показываем результат только для выбранного значения и сравниваем его с моделью без регуляризации.

## 7. Результаты

| Вариант | RMSPE | MAE |
|---|---:|---:|
| Линейная регрессия без исторических признаков | 20,33% | 931,78 |
| Линейная регрессия с историческими признаками | 15,64% | 746,86 |

На последних 42 днях RMSPE снизился на 4,69 процентного пункта, или на 23,05% относительно модели без истории. Чтобы оценить, насколько результат зависит от состава магазинов, 1000 раз случайно выбирали магазины с возможностью повторов и брали все дни каждого выбранного магазина. Получили 95%-й бутстрап-интервал от 21,1% до 24,9%. Отдельные периоды ниже показывают, как меняется результат во времени.

| Окно | RMSPE без истории | RMSPE с историей |
|---|---:|---:|
| 28.03 по 08.05.2015 | 23,39% | 18,50% |
| 09.05 по 19.06.2015 | 21,27% | 16,77% |
| 20.06 по 31.07.2015 | 20,33% | 15,64% |
| Среднее ± стандартное отклонение | 21,66% ± 1,57 п.п. | 16,97% ± 1,44 п.п. |

Среди 856 магазинов из `test.csv` на тех же 42 днях есть 30 960 строк с положительной выручкой. Для этих магазинов добавление истории снижает RMSPE с 18,36% до 14,98%, или на 18,4%.

### Линейная регрессия с L2-регуляризацией

L2 добавляет штраф за большие коэффициенты. На двух ранних периодах лучшее значение оказалось `alpha=10`, средний RMSPE модели с историей составил 17,537%. Применили это значение к обеим версиям на последних 42 днях.

| Набор признаков | RMSPE без регуляризации | RMSPE с L2 |
|---|---:|---:|
| Без истории | 20,33% | 20,36% |
| С историей | 15,64% | 15,58% |

У модели с историей RMSPE снизился примерно на 0,07 процентного пункта, а MAE с 746,86 до 740,25. У модели без истории RMSPE немного вырос.

### Примеры ошибок

Для каждой группы взяли по одному примеру, где модель с историей ошиблась сильнее, чем примерно в 90% случаев в этой группе.

| Срез | Магазин и дата | Факт | Прогноз | Ошибка |
|---|---|---:|---:|---:|
| Низкая выручка | 5, 20.06.2015 | 2088 | 2974 | +42,4% |
| День с акцией | 551, 30.07.2015 | 6429 | 7825 | +21,7% |
| День без акции | 475, 06.07.2015 | 5035 | 6082 | +20,8% |

- Магазин 5. Выручка 2088 близка к обычной субботе без акции, для которой медиана равна 2001. При этом средняя выручка магазина за 28 дней до прогноза равна 4812. Модель с историей снизила прогноз с 3611 до 2974, но все еще завысила его. Вероятно, общий уровень продаж магазина получил слишком большой вес для субботы.
- Магазин 551. Фактические 6429 близки к медиане четвергов с акцией (6538). Продажи за соответствующую дату год назад были заметно выше (10 644). Это возможная причина, почему модель с историей прогнозировала больше (7825), чем базовая (7179).
- Магазин 475. Медиана семи недавних понедельников равна 8547, но в пяти из них шла акция. В два понедельника без акции медиана была 5623, ближе к фактическим 5035. Недавняя медиана объединяет дни с акциями и без них и могла завысить прогноз для обычного понедельника.

Это возможные объяснения на основе истории магазина. На 10% дней с самой низкой положительной выручкой модель завышает прогноз в 77,2% случаев. RMSPE в этой группе равен 28,39%, на нее приходится 32,9% суммы квадратов относительных ошибок. Среди остальных дней RMSPE равен 13,51% с акциями и 13,50% без акций.

## 8. Выводы

На всех трех периодах история продаж снизила RMSPE больше чем на 5%. Проверка охватывает одну сеть и три периода в 2015 году.

### Ответы на исследовательские вопросы

1. Тренд. Сглаженный тренд повысил RMSPE с 15,49% до 15,64% и MAE с 745,96 до 746,86. На основном периоде он не помог.
2. Продажи год назад. На днях с доступной прошлогодней выручкой признак снизил RMSPE с 16,31% до 15,62% и MAE с 778,66 до 740,78.
3. Всплески. Убрали 55 всплесков у 38 магазинов и сравнили 1363 прогноза за дни с положительной выручкой.

   | Какая история у той же модели | RMSPE | MAE |
   |---|---:|---:|
   | Со всплесками | 20,40% | 712,41 |
   | После удаления всплесков | 20,32% | 709,59 |

   Половина прогнозов изменилась не больше чем на 1,5 единицы выручки, а 90% прогнозов изменились не больше чем на 9,7. Самое заметное изменение было у магазина 303 на 14 июля. Всплеск пришелся на дату, из которой брали продажи год назад. Когда вместо 27 318 подставили медиану 6281, прогноз снизился с 9483 до 7148 при фактической выручке 7797. В отдельном сравнении на тех же днях среднее по магазину и дню недели дало 20,31% RMSPE, медиана дала 20,40%.

В следующем эксперименте можно проверить, снизится ли ошибка, если считать недавнюю медиану отдельно для дней с акцией и без нее. Пример магазина 475 показывает, где такая поправка может помочь.
